# EduTrace PoC 验证与验收计划 V0.1

> **先验证，再承诺。** 未通过真实教辅测试的场景不得标记为“已支持”。记录样本、权重哈希、参数、硬件环境、变换条件和失败样本。

## 1. 样本准备

所有素材须为自制、公开许可或经明确授权的脱敏内容。

| 媒介 | 基准样本 |
|---|---|
| PDF | 文字密集试卷、10 页讲义、表格/图片/公式/古诗文混排 |
| PPTX | 纯文字、图片、表格、图表、母版、动画、字体替换、SmartArt 等复杂页 |
| PNG/JPEG | 照片、图表、黑白教材扫描、低纹理白底页 |
| 视频 | 1080p 课件录屏、讲师实拍、混合画面；不同帧率/方向 |

不要把真实学生名单、课程私密数据、客户文档或密钥上传仓库。

## 2. 必测场景矩阵

| 格式 | 原生操作 | 破坏性/跨格式操作 | 保真要求 |
|---|---|---|---|
| PDF | 打开、复制、搜索、批注、另存 | 截图、导出图片、打印扫描、手机斜拍、裁剪 | 页面结构、字体、文字可选中性 |
| PPTX | 编辑文字/图形/图片/表格、增删页、另存 | 导出 PDF、截图、录屏、字体替换 | **必须保留原生可编辑**；验证母版、动画、图表 |
| PNG/JPEG | 打开与重新保存 | JPEG 多质量、缩放、裁剪、旋转、拍照 | 视觉质量和文字可读性 |
| MP4 | 正常播放、剪辑片段 | H.264 重编码、缩放、录屏、片段截取 | 音画同步、时长、帧率、无明显闪烁 |

PPTX 要在 Microsoft PowerPoint 与 WPS 两种环境验证。不能安全处理的对象必须返回“跳过及原因”，不能以整页截图替代可编辑内容。

## 3. 核心指标

- **TDR**：带有效指纹样本的正确认证比例，按“格式×变换×强度”分开统计。
- **FPR**：负样本错误归属某分发记录的比例，并报告样本量与置信区间。
- **BER**：载荷位错误率；区分算法原始解码与认证结果。
- **文件保真**：PPT 可编辑对象、母版、动画、图表是否保留；PDF 可搜索/复制；视频音画同步。
- **视觉质量**：图片 PSNR/SSIM/LPIPS，视频 VMAF/闪烁指标及人工盲测；白底文字另评可读性。
- **资源成本**：每页/每分钟视频处理时间、CPU/GPU/内存峰值、输出大小变化。
- **碎片检出**：单页/半页照片，10/30/120 秒视频片段分别统计。

所有指标须明确分母，区分不支持、处理失败、未检出和错误归属。

## 4. 阶段验收门槛

- **G0 原生结构链路**：PDF/PPTX 分发标识可写入和验证；后端映射与认证校验有效；负样本不误认。
- **G1 编辑兼容性**：PPTX 可打开、修改文本/图形、保存和再打开；动画和母版等复杂对象不发生不可接受的损坏。
- **G2 视觉水印基线**：图片与视频至少各完成一个候选算法的嵌入、变换、提取和负样本测试，保存可复现结果。
- **G3 技术路线决策**：针对打印拍照、纯文字页截图、短视频泄露分别给出 Go / No-Go / Further Research 结论。

G0/G1 要求达到测试集中全部预定义兼容性案例；对 G2/G3 的识别率**不先写无法证实的百分比承诺**，取得样本统计后再定义上线阈值。
